#### SELECT Statement

**Answer**:

defination: The `SELECT` statement is used to select data from a database.

Syntax:

```sql
 SELECT column1, column2, ... FROM table_name;
```

#### WHERE Clause

**Answer**:

defination:The `WHERE` clause is used to filter records.It is used to extract only those records that fulfill a specified  condition.

Syntax: 

```sql
SELECT column1, column2, ... FROM table_name WHERE condition;
```
